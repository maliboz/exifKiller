# Security Policy

## Supported Versions

The current alpha line is the supported release line:

- `0.1.x-alpha`

## Reporting a Vulnerability

Please avoid opening public issues for new security vulnerabilities.

Use one of these routes instead:

1. Open a private GitHub security advisory if the repository has advisories enabled.
2. If advisories are not available, contact the maintainers privately before disclosure.

Include the following when reporting:

- affected version
- operating system
- proof of concept or reproduction steps
- whether the issue can expose files, metadata, or execution

We will aim to acknowledge reports within 7 days and share a remediation plan as quickly as possible.

## Project Security Notes

- Exif Killer is designed to work offline.
- The alpha release does not include telemetry, cloud APIs, or automatic update services.
- Verification output should be reviewed before relying on a cleaned file in a sensitive workflow.
